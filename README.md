# 🎮 Jajanken Showdown

A Hunter × Hunter inspired Rock-Paper-Scissors battle built using HTML, CSS, and JavaScript.

Inspired by Gon's iconic **Jajanken** ability, this project transforms the classic Rock-Paper-Scissors game into a stylish Nen battle with animated effects and a futuristic UI.

---

## ✨ Features

- ⚡ Hunter × Hunter inspired theme
- ✊ GUU (Rock)
- ✌️ CHI (Scissors)
- ✋ PAA (Paper)
- 🎨 Dynamic Nen aura colors
- 🔥 Animated countdown
- 🏆 Live score tracking
- 🎭 Random opponents
- 📱 Responsive design
- ♿ Keyboard accessible controls

---

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

---

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/hunterxhunter-rps.git
```

Open:

```
index.html
```

or use Live Server in VS Code.

---

## 🎮 Gameplay

1. Choose your Nen technique.
2. Watch the countdown.
3. The opponent randomly chooses a move.
4. Winner is determined using classic Rock-Paper-Scissors rules.
5. First to get the highest score wins.
