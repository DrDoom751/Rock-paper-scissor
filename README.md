# Jajanken Showdown

A Hunter × Hunter-inspired rock–paper–scissors browser game made for CosHack. Choose **Guu** (rock), **Chii** (scissors), or **Paa** (paper), then play through the animated countdown against a randomized opponent.

## Play locally

Open [index.html](index.html) in a modern browser. The game uses plain HTML, CSS, and JavaScript; no build step is needed.

## What is in the repository

- [index.html](index.html) — game layout and controls
- [style.css](style.css) — responsive styling and animation
- [script.js](script.js) — round logic, opponent selection, and scoring

The game includes a live score display and keyboard-accessible controls. This is an unofficial fan project; Hunter × Hunter and its characters belong to their respective rights holders.
